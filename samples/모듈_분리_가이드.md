# 행정도_설계_샘플.bas 모듈 분리 가이드

**목적**: 22,101 줄 단일 .bas 가 VBA P-code 64KB 한계 초과 → 「메모리가 부족합니다」 임포트 오류.
**해결**: 5 개 모듈로 분할. 동작 100% 동일 유지.

## 분할 결과

| 파일 | 줄 수 | 내용 |
|---|---|---|
| **M1_Setup.bas** | ~4,015 | 상수·전역변수·셋업·범례·시트 보호·버튼·리본 |
| **M2_Facility.bas** | ~4,505 | 배지·메타정리·Undo/Redo·시설물 배치·케이블 그리기·정보·삭제 |
| **M3_PairBox.bas** | ~5,025 | 선번박스 텍스트 처리·선번연결 도구 전반 |
| **M4_RNGroup.bas** | ~3,990 | 선번연결 도구 RN·접속함체 그룹 |
| **M5_Helpers.bas** | ~4,583 | 선번연결 해제·정보 동기화·메타 헬퍼·코어 추적·이벤트 핸들러 주입 |

각 모듈 ≈ 30~50KB P-code → 64KB 한계 여유.

## 주의 — 동작 보존 원리

- **모든 함수 그대로** — 이름·인자·로직 변경 0
- **Private → Public 일괄 승격** — 다른 모듈에서 호출 가능하도록. 동작 차이 없음 (네임스페이스 노출만 늘어남)
- **전역 변수 (g_*) Public 승격** — 다른 모듈에서 읽기·쓰기 가능
- **Const 도 Public** — 다른 모듈에서 참조 가능
- **ThisWorkbook 모듈·시트 모듈**: 변경 불필요. 기존 `Workbook_Open`, `Sheet_SelectionChange` 가 Public 함수를 그대로 호출

## 임포트 절차

### 1. 사전 작업
- Excel 종료
- 다른 모든 Excel 인스턴스 종료 (작업 관리자 → 자세히 → `EXCEL.EXE` 0 개 확인)
- 백신·OneDrive 동기화 일시 중지 (사용 중이면)

### 2. .xlsm 매크로 비활성으로 열기
- 파일 탐색기 → `행정도_설계_샘플.xlsm` Shift+우클릭 → **「콘텐츠 사용 안 함」** 또는
- Excel 열고 「매크로 사용 안 함」 선택 (보안 알림 뜰 때)
- 이렇게 해야 `Workbook_Open` 이 안 돌아 임포트 작업 중 오류 회피

### 3. VBE 열기
- `Alt+F11`

### 4. 기존 모듈 제거
프로젝트 트리에서 **AdminMapDesigner** (또는 기존에 .bas 를 임포트한 모듈 이름):
1. 우클릭 → **「AdminMapDesigner 제거」**
2. **「내보낼까요?」** 다이얼로그 → **「아니요」** (백업 안 만들어도 됨. 원본 .bas 가 있으니까)

### 5. 5 개 모듈 차례로 임포트
**파일 → 파일 가져오기** 메뉴 (또는 `Ctrl+M`):

순서대로:
1. `M1_Setup.bas`
2. `M2_Facility.bas`
3. `M3_PairBox.bas`
4. `M4_RNGroup.bas`
5. `M5_Helpers.bas`

(순서 무관하지만 위 순서가 의존성 흐름이라 깔끔)

각 임포트마다 「메모리가 부족합니다」 안 나와야 정상.

### 6. 컴파일 검증
VBE 메뉴 **디버그 → VBAProject 컴파일** (`Alt+D, L`):
- 오류 없으면 → 임포트 성공
- 오류 뜨면 → 어느 함수가 미정의인지 확인 후 알려주세요 (전 5 개 모듈 함수가 다 Public 이라 거의 없을 것)

### 7. 저장
`Ctrl+S` → 「Excel 매크로 사용 통합 문서 (.xlsm)」 형식으로 저장

### 8. 매크로 활성화로 재오픈
- Excel 종료 → 다시 열기 → 「콘텐츠 사용」 클릭
- `Workbook_Open` 정상 실행되면 → 셋업 완료

## 문제 발생 시 복구

원본은 다음 파일에 백업:
- `행정도_설계_샘플.bas.원본백업_20260607`

복구 방법:
1. 5 개 모듈 모두 제거 (M1~M5)
2. `.원본백업_20260607` 의 확장자를 `.bas` 로 변경한 사본 임포트 ← 「메모리 부족」 다시 발생 가능

→ 더 깨끗한 복구: 백업한 .xlsm 파일 사용

## 향후 코드 수정

기존 1 개 모듈 → 5 개 모듈 흩어짐. 수정 시:
- **함수 위치 찾기**: VBE 에서 `Ctrl+F` 로 함수명 검색 → 해당 모듈로 이동
- **이벤트 핸들러 (Workbook_Open, SelectionChange 등)**: ThisWorkbook / 시트 모듈에 그대로
- **새 함수 추가**: 5 개 중 의미적으로 맞는 모듈에 추가
- **상수·전역 변수 추가**: M1_Setup 의 상단 declarations 섹션에
