## 1. 개요

### 보호 메커니즘
- **사용자별 라이센스** — 발급 시 수령자 이름·발급일·만료일 영구 embed
- **PC 바인딩** — 발급 시 사용자 PC ID (COMPUTERNAME + USERNAME) 를 지정해야 실행됨. HW 미지정·다른 PC = 차단 (2026-06-16: 첫 launch 자동 바인딩 폐지 — 저장 실패로 잠금이 무력화되던 약점 제거)
- **변조 방지** — DJB2 해시 + secret SALT 로 라이센스 정보 위변조 검증
- **만료 + 유예** — 만료일 도달 시 14 일 사전 경고, 만료 후 7 일 유예 후 차단
- **워터마크** — 유출 시 출처 식별을 위한 사용자 정보 숨김 embed
- **VBA 프로젝트 암호** — 코드 (특히 SALT) 보호용 1차 차단

### 보호되지 않는 것 (솔직한 한계)
- 로직 자체의 reverse engineering (강한 동기부여 공격자엔 무력)
- 화면 캡처·스크린샷
- 파일 내용 (사용자가 만든 설계) 의 외부 export

→ **사용 권한 차단 + 유출자 추적** 목적. 「로직 비공개」 가 아닌 「무단 사용 방지」.

### 파일 종류 구분

| 파일 | 용도 | 라이센스 상태 |
|---|---|---|
| **master 파일** | owner 가 개발·발급에 사용 | `LicenseDevMode = "true"` → 검증 skip |
| **배포본** | 사용자별 별도 파일 (수령자명·HW 바인딩 포함) | 정상 검증 활성 |

## 2. 관리자 매뉴얼 (owner 전용)

### 2-1. 최초 1 회 설정

**Step 1. VBA 프로젝트 암호 설정** (가장 중요)

1. Excel 열고 master 파일 열기
2. `Alt + F11` → VBE 진입
3. 좌측 트리에서 「VBAProject (행정도_설계_샘플.xlsm)」 우클릭 → **「VBAProject 속성」**
4. **「보호」** 탭 클릭
5. ✅ **「프로젝트 잠금 + 보기 위한 암호」** 체크
6. **암호 입력** — 16 자 이상 강력 추천 !@#$(예: `MyP@ssw0rd_2026_LGUplus`)
7. **암호 확인** — 동일 입력
8. **확인** 클릭
9. 파일 저장 (`Ctrl+S`)
10. 닫고 다시 열기 → VBE 에서 모듈 더블클릭 시 「암호 입력」 다이얼로그 ⇒ 정상

⚠ **암호 분실 시 코드 영구 손실** (백업 권장)
⚠ 암호는 owner 만 알아야 함. 절대 코드/매뉴얼에 적지 말 것.

**Step 2. master 파일 DEV 모드 확인**

1. master 파일 열기 (암호 입력 후)
2. `Alt + F8` → **`라이센스_정보_보기`** 실행
3. MsgBox 마지막에 「⚠ DEV 모드 — 검증 skip (master 파일)」 표시되어야 정상
4. 표시 안 되면 다음 명령 실행:
   - VBE 즉시 창 (`Ctrl + G`) 열기
   - 입력:
     ```
     ThisWorkbook.CustomDocumentProperties.Add Name:="LicenseDevMode", LinkToContent:=False, Type:=4, Value:="true"
     ```
   - Enter
   - 파일 저장
   - 다시 `라이센스_정보_보기` 로 확인

**Step 3. 백업**

1. master 파일을 외부 저장소 (USB·클라우드) 에 백업
2. VBA 암호도 별도 안전한 곳에 기록

### 2-2. 사용자에게 배포본 발급

**Step 1. 사용자에게 HW ID 요청** (선택)

사용자에게 메시지:
> "edenMG 사용을 위해 본인 PC HW ID 를 알려주세요. 받으신 파일을 열고 `Alt+F8` → `라이센스_내_HW_ID_보기` 실행 → 화면에 나오는 값 복사해서 전달."

→ 사용자가 보내준 HW ID 형식: `PC01|HONG`

⚠ **HW ID 는 필수입니다.** 비워두고 발급하면 그 배포본은 어느 PC 에서도 차단됩니다 (2026-06-16 자동 바인딩 폐지). 사용자가 HW 를 못 보내오는 경우: 받은 파일을 열면 「HW 미지정」 차단 화면에 **현재 HW** 값이 표시되니, 그 값을 받아 재발급하세요.

**Step 2. 발급 실행**

1. master 파일 열기 (DEV 모드 상태)
2. `Alt + F8` → **`라이센스_발급`** 실행 (또는 리본 「추가 기능 > 라이센스 > 라이센스 발급」)
3. **1/3 — 수령자 이름** 입력 (예: `홍길동`)
4. **2/3 — 유효기간** 입력 (예: `90` = 90 일)
5. **3/3 — HW ID** 입력 (**필수**):
   - Step 1 에서 받은 값 (예: `PC01|HONG`)
   - 비우면 경고가 뜨고, 그대로 발급하면 그 배포본은 어느 PC 에서도 차단됨 (HW 받아 재발급 필요)
6. 발급 정보 확인 MsgBox → **「예」** 클릭 (새 파일로 저장)
7. 저장 다이얼로그 → 파일명 자동 채워짐 (예: `edenMG_홍길동_2026-06-06.xlsm`) → 저장
8. master 자동 DEV 모드 복원
9. 완료 MsgBox 의 경로에 배포본 생성 확인

**Step 3. 사용자에게 전달**

- 생성된 .xlsm 파일을 안전한 채널 (이메일·USB·내부 공유 폴더) 로 전달
- 다음 안내 함께 송부:
  - 첫 실행 시 「라이센스 활성화: …」 메시지 확인
  - 만료일 (예: 2026-09-04) 사전 안내
  - 사용자 매뉴얼 (3 장) 링크

### 2-3. 라이센스 갱신

**상황**: 사용자 라이센스가 만료 임박/만료. 사용 계속 필요.

**Step 1. 사용자로부터 파일 받기**

- 사용자가 사용 중인 .xlsm 파일을 owner 에게 다시 전달 (이메일·USB)

**Step 2. 갱신 실행** (2026-06-16: 갱신·발급은 **DEV 모드에서만** 동작 — 사용자 자가 연장 차단)

받은 파일은 배포본(DEV OFF)이라 바로 갱신되지 않습니다. 둘 중 하나로:

**방법 A — 받은 파일에 DEV 임시 ON 후 갱신** (HW·이름 유지, 권장)
1. 받은 파일 열기 (만료 splash 떠도 OK — 매크로 실행 가능)
2. VBE `Ctrl+G` 즉시창에 입력:
   ```
   ThisWorkbook.CustomDocumentProperties.Add Name:="LicenseDevMode", LinkToContent:=False, Type:=4, Value:="true"
   ```
3. `Alt+F8` → `라이센스_갱신` → 추가 기간 입력 → 새 만료일 확인
4. ⚠ **반드시 DEV 끄기** (안 끄면 그 파일이 어느 PC 에서도 열림):
   ```
   ThisWorkbook.CustomDocumentProperties("LicenseDevMode").Delete
   ```
5. 저장(`Ctrl+S`) → 사용자에게 회신

**방법 B — master 에서 재발급** (더 깨끗)
- 사용자 HW 확인: 받은 파일에서 `라이센스_정보_보기` 의 「바인딩 HW」
- master(DEV)에서 `라이센스_발급` → 같은 이름·같은 HW·새 기간 → 새 배포본 SaveAs → 회신

**Step 3. 사용자에게 전달**

- 갱신된 파일을 사용자에게 보내기
- 사용자가 같은 PC 에서 열면 정상 작동

### 2-4. 사용자 PC 변경 시 재발급

**상황**: 사용자가 새 PC 로 옮김. 기존 라이센스는 옛 PC 에 바인딩되어 새 PC 에서 차단됨.

**Step 1. 새 HW ID 요청**

사용자에게 새 PC 에서 「내 HW ID 확인」 매크로 실행 후 결과 전달 요청.

→ 단, 새 PC 에서는 라이센스 차단 상태라 사용자가 `라이센스_내_HW_ID_보기` 실행 가능 여부 확인. 차단 시에도 `Alt+F8` 의 매크로 목록엔 함수가 노출됨.

**Step 2. 새 라이센스 발급**

1. master 파일 열기 (DEV 모드)
2. `Alt + F8` → `라이센스_발급` 실행
3. 이전과 동일한 사용자 이름 + 새 HW ID 입력
4. 새 배포본 SaveAs → 사용자에게 전달

**또는 더 간단**: 기존 파일 받아서 갱신 매크로로 HW ID 만 변경 가능 (하지만 발급 절차가 더 깨끗함).

### 2-5. 라이센스 해제 (배포 종료 시)

**상황**: 사용자가 더 이상 도구 사용 안 함. 사용 권한 회수 + 파일 폐기 요청.

**Option A. 즉시 만료**

1. 사용자로부터 파일 받기
2. 2-3 의 「방법 A」 처럼 **DEV 임시 ON** (갱신은 DEV 모드에서만 동작)
3. `Alt + F8` → `라이센스_갱신` → 추가 기간 **음수** 입력 (예: `-365`) → 어제 만료
4. **DEV 끄기** + 저장 → 사용자에게 「만료됨」 안내 + 파일 삭제 요청

> DEV 토글이 번거로우면 **Option B(속성 직접 삭제)** 가 더 간단 — 갱신 매크로 불필요.

**Option B. 라이센스 자체 제거** (전체 초기화)

1. 사용자로부터 파일 받기
2. VBE 즉시창 (`Ctrl + G`) 에 다음 입력:
   ```
   ThisWorkbook.CustomDocumentProperties("LicenseUser").Delete
   ThisWorkbook.CustomDocumentProperties("LicenseIssued").Delete
   ThisWorkbook.CustomDocumentProperties("LicenseExpires").Delete
   ThisWorkbook.CustomDocumentProperties("LicenseHWID").Delete
   ThisWorkbook.CustomDocumentProperties("LicenseHash").Delete
   ```
3. 파일 저장
4. 다시 열면 「라이센스 정보 없음」 차단

**Option C. 그냥 파일 삭제 요청** — 사용자가 협조한다면 간단

## 3. 사용자 매뉴얼

### 3-1. 첫 사용

1. 관리자로부터 받은 .xlsm 파일을 본인 PC 에 저장
2. Excel 로 파일 열기 → 「**보안 경고: 매크로가 사용 안 함**」 노란 막대 표시
3. **「콘텐츠 사용」** 클릭 → 매크로 활성화
4. 발급 시 본인 PC HW 가 지정돼 있으면 → 바로 정상 사용
5. 「HW 미지정」 또는 「다른 PC 전용」 차단 화면이 뜨면 → 화면의 **현재 HW** 값을 관리자에게 전달해 재발급 요청

⚠ 2026-06-16 부터 **첫 launch 자동 바인딩 폐지** — HW 는 발급 시 지정돼야 실행됩니다. (보호된 보기·읽기전용·OneDrive 에서 첫 실행 저장이 실패해 잠금이 무력화되던 문제 제거)

---

### 3-2. 라이센스 상태 확인

`Alt + F8` → **`라이센스_정보_보기`** 실행 → 다음 정보 확인:
- 수령자 이름
- 발급일
- 만료일
- 바인딩된 HW
- 현재 HW
- 남은 일수

---

### 3-3. 만료 임박 대응

**14 일 이내 만료** 시:
- 화면 하단 상태표시줄에 「라이센스가 N 일 후 만료. 관리자에게 갱신 요청 권장.」 표시
- 정상 사용 가능

**만료일 도달 시**:
- 매번 「라이센스 유예 — N 일 후 차단」 경고
- 7 일까지 정상 사용 가능 (유예 기간)
- 그 동안 관리자에게 갱신 요청

**만료 + 7 일 경과 시**:
- 시트 자동 숨김 + 「라이센스 만료」 차단 메시지
- 사용 불가

**갱신 요청 절차**:
1. 관리자에게 메시지: 「라이센스 만료 임박 / 만료. 갱신 부탁드립니다.」
2. 현재 사용 중인 .xlsm 파일 전달
3. 관리자가 갱신 후 새 파일 회신
4. 받은 파일로 교체 → 사용 재개

---

### 3-4. 발급/재발급 요청

**새 발급 요청** (처음 받을 때):
1. (관리자가 HW ID 묻는 경우) 다음 절차로 HW ID 확인:
   - 관리자에게 받은 임시 파일 또는 다른 사용자의 master 파일 열기
   - `Alt + F8` → `라이센스_내_HW_ID_보기` 실행
   - 화면의 HW ID 복사 (예: `PC01|HONG`)
2. 관리자에게 다음 정보 전달:
   - 본인 이름
   - HW ID
   - 사용 기간 희망 (예: 3 개월)

**재발급 요청** (PC 변경, 분실 등):
1. 새 PC 에서 도구 열기 → 「PC 불일치」 메시지 표시
2. `Alt + F8` → `라이센스_내_HW_ID_보기` (또는 차단 상태라도 메뉴 실행 가능)
3. 새 HW ID 와 사유를 관리자에게 전달
4. 관리자가 새 배포본 발급 → 새 파일 받기

---

### 3-5. 문제 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 「라이센스 정보 없음」 | 미발급 파일 | 관리자에게 발급 요청 |
| 「라이센스 변조 감지」 | 파일 손상/변조 | 관리자에게 재발급 요청 |
| 「PC 불일치」 | 다른 PC 에서 실행 | 관리자에게 새 HW ID 로 재발급 요청 |
| 「라이센스 만료」 | 만료 + 유예 경과 | 관리자에게 갱신 요청 |
| 시트 안 보임 | 검증 차단 상태 | 위 원인 중 하나 — 관리자 문의 |
| 「매크로 차단됨」 (Excel 보안 경고) | 매크로 비활성 | 「콘텐츠 사용」 클릭 |

## 4. 자주 묻는 질문 (FAQ)

**Q1. 파일을 동료에게 공유해도 되나요?**
A. 아니요. 파일은 본인 전용입니다. 동료가 자기 PC 에서 열면 차단됩니다 (HW 불일치). 동료가 필요하면 관리자에게 별도 발급 요청해주세요.

**Q2. PC 를 새로 샀습니다.**
A. 관리자에게 「PC 변경 + 새 HW ID」 정보 전달 → 재발급 받으세요.

**Q3. Excel 다시 설치하면 어떻게 되나요?**
A. PC HW ID 는 COMPUTERNAME + USERNAME 기반이라 Excel 재설치는 영향 없음. 단 Windows 계정명 변경/PC 이름 변경 시 재발급 필요.

**Q4. 라이센스 만료된 줄 모르고 작업 중이었습니다.**
A. 만료일 14 일 전부터 매번 안내가 표시됩니다. 만료 후 7 일 유예가 있어 작업 중 갑자기 막히지 않습니다.

**Q5. 만료 직후 작업한 파일은 잃어버리나요?**
A. 작업 내용 (시설물·케이블·코어 등) 은 데이터로 보존됩니다. 시트가 숨겨질 뿐. 갱신 후 다시 표시됩니다.

**Q6. 관리자가 파일 갱신해줄 때 내 작업 데이터는 안전한가요?**
A. 갱신은 라이센스 정보만 수정합니다. 시설물·케이블·코어 데이터는 그대로 유지됩니다.

**Q7. master 파일과 배포본 파일을 구분하는 방법?**
A. `라이센스_정보_보기` 결과에 「⚠ DEV 모드」 표시 = master. 표시 없음 = 배포본.

**Q8. 매크로가 무서운데 안전한가요?**
A. owner 가 본인 명의로 발급한 신뢰 매크로입니다. 매크로 활성화 안 하면 라이센스 검증도 안 되고 시트도 영원히 숨겨진 상태로 남습니다.

## 5. 보안 권장사항

### owner
1. **VBA 암호** 분실 방지 — 별도 안전한 곳에 기록 (예: 1Password, KeePass)
2. **SALT 값 외부 노출 금지** — 코드 안에 있고 VBA 암호로 가려져 있음
3. **master 파일 백업** — 외부 저장소 (USB, 클라우드)
4. **발급 기록 별도 관리** — 누구에게 언제 발급했는지 별도 스프레드시트 (필요 시 추적)
5. **갱신 주기 짧게** — 90 일보다 짧게 (30~60 일) 권장. 강제 contact 유지

### 사용자
1. **파일 무단 공유 금지** — 동료 필요 시 관리자에게 발급 요청
2. **백업** — 본인 작업 데이터는 정기 백업
3. **PC 변경 예정** — 미리 관리자에게 알리고 미리 새 HW ID 받기
4. **이상 동작 시 즉시 보고** — 변조·차단 등 메시지는 즉시 관리자 문의

### 운영
- 사용자가 떠날 때: **즉시 라이센스 해제** (Option A — 음수 갱신) + 파일 회수
- 정기 점검: 발급 기록 vs 현재 사용자 매칭. 미사용 라이센스 해제
- 유출 의심 시: 워터마크 (`_라이센스_안내` 시트 Z1000 셀) 의 값으로 출처 추적 가능

## 부록 — VBE 즉시창 명령 모음

문제 해결용. 모두 master 파일 열고 VBE → `Ctrl + G` 즉시창에서 실행.

### DEV 모드 켜기 (master 파일이 일반 검증으로 잘못 설정된 경우)
```vba
ThisWorkbook.CustomDocumentProperties.Add Name:="LicenseDevMode", LinkToContent:=False, Type:=4, Value:="true"
```

### DEV 모드 끄기 (배포본으로 만들 때)
```vba
ThisWorkbook.CustomDocumentProperties("LicenseDevMode").Delete
```

### 라이센스 정보 전체 출력
```vba
?ThisWorkbook.CustomDocumentProperties("LicenseUser").Value
?ThisWorkbook.CustomDocumentProperties("LicenseExpires").Value
?ThisWorkbook.CustomDocumentProperties("LicenseHWID").Value
```

### 라이센스 전체 삭제 (해제)
```vba
ThisWorkbook.CustomDocumentProperties("LicenseUser").Delete
ThisWorkbook.CustomDocumentProperties("LicenseIssued").Delete
ThisWorkbook.CustomDocumentProperties("LicenseExpires").Delete
ThisWorkbook.CustomDocumentProperties("LicenseHWID").Delete
ThisWorkbook.CustomDocumentProperties("LicenseHash").Delete
```

### 검증 강제 호출 (재발급 후 동작 확인)
```vba
?라이센스_검증
```

### 워터마크 확인 (유출 추적 시)
```vba
?Worksheets("_라이센스_안내").Range("Z1000").Value
```
